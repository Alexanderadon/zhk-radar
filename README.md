# ЖК-Радар

**Krisha показывает, что продаётся. ЖК-Радар показывает, стоит ли это покупать.**

Карта новостроек Алматы с прозрачным риск-баллом застройщика из открытых проверяемых данных: гарантии долевого участия (КФГЖС), трек застройщика, сейсмостойкость, паркинг, статус стройки. Каждый фактор — со ссылкой на первоисточник.

Третий проект в экосистеме «данные о жизни в КЗ»: воздух (almaty-air), зарплаты (tengestack), жильё (этот).

## Стек
- Next.js 15 (App Router, SSG) + TypeScript + SCSS Modules
- MapLibre GL JS + OpenFreeMap (тайлы без ключей, $0)
- Данные-как-код: JSON в git, без БД (история = аудит)
- Коллекторы: Node 22, запуск с локального IP Алматы (cloud-IP режут .kz)

## Данные
- `data/zhk.json` — каталог ЖК Алматы (korter.kz: гео, класс, цена, паркинг, застройщик, сейсмика)
- `data/guarantees.json` — реестр гарантий КФГЖС (khc.kz PDF)
- Источник истины — `data/`. Всё derived (скор, статистика) считается в `lib/`.

## Команды
```bash
pnpm install
pnpm collect          # korter каталог + обогащение деталями
pnpm collect:kzhk     # гарантии КФГЖС (PDF → guarantees.json)
pnpm dev              # дашборд на :3300
pnpm build            # статическая сборка
```

## Обновление
Еженедельный ритуал — скилл `/weekly` (`.claude/skills/weekly/`): прогнать коллекторы → diff → коммит → `vercel --prod`.

## Методология скора
Публичная страница `/methodology`. Веса (сумма 100): гарантия 29, трек 23, возраст 15, стоп-строй 12, суды 11, отзывы 10. Балл = средневзвешенное по факторам **с данными**, приведённое к 0–100. Нет данных → серый, не ноль (не выдумываем).

## Статус
Собран за один заход поверх разведки источников (Фаза 0, вердикт GO). См. `PLAN.md`, `DATA-SOURCES.md`.
Подключено: каталог korter (222 ЖК), обогащение деталями, скор, карта, карточки ЖК/застройщиков, методология.
